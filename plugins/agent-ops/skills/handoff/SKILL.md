# handoff — 引き継ぎプロンプトの生成

タスクの区切りで会話の状態を整理し、次の会話が即動き出せる引き継ぎプロンプトを作る。引き継ぎ先が要るものだけ選び、完了済みは結果だけ書く（経緯は残さない）。

残タスクが独立して並行できるなら、プロンプトを分割して複数出す。基準は、タスク間に依存がなく統合時に競合しないことである。迷うなら分割しない。

## 手順

1. 会話と git の状態から、各タスクの目的・完了条件・進捗・関連資料を拾う
2. 残タスクを洗い出し、並行できるか判断する
3. タスクごとにテンプレートを埋め、コードブロックで囲って出す
   - プロンプト本文の中でコード例を示すときは、フェンス（```）で囲まず、インラインコードや地の文で表現する
     - フェンスを入れ子にすると外側のコードブロックが途中で閉じ、人がコピーできなくなる

## テンプレート

該当しない項目は削る。

```markdown
## タスク引き継ぎ: {タスク名}

### 目的と完了条件

{達成したいこと}

- [ ] {確認できる完了条件}

### 現在の状態

- ブランチ / 関連 Issue・PR: {あれば}
- できていること: {結果のみ}
- できていないこと・課題: {残りと、解決待ちのブロッカー}

### 参考資料・関連

- 参考資料
  - {Issue・PR・外部ドキュメント}
- 関連タスク
  - {並行/後続タスクとの関係}
```

## 複数タスクのとき

番号と並行可否を添えて、それぞれコードブロックで出す。

````markdown
タスク 1 / 2 — {タスク名}

```
{プロンプト本文}
```

タスク 2 / 2 — {タスク名}（タスク 1 と並行作業できます）

```
{プロンプト本文}
```
````
