# 語彙の事例

readable-japanese の語彙規則を支える事例である。規則そのものは SKILL.md にあり、ここは証拠として置く。

判定は SKILL.md の問いで行う。表に無い語も同じ問いで裁く。

> 同じ分野の日本語話者が、この語を口に出すか。

## 直訳を持ち込んだ語

英語の語を置き換えただけで、日本語の同種の文書に出てこない語である。

| 出がちな語 | 直した語 | 元の語 |
| --- | --- | --- |
| 病理 | 原因 / 症状 | pathology |
| 出荷 | 公開 / 提出 / 投稿 | ship |
| 発火 | 発動 | fire / trigger |
| 表面化する | 洗い出す | surface |
| 優雅に | 穏当に / 安全に | gracefully |
| 第一級の | 標準の / 正式に対応した | first-class |
| 頑健 | 堅牢 | robust |
| 主柱 | 主軸 | spine |
| 意見のある | 方針が明確な | opinionated |
| 依存バンプ | 依存の更新 | dependency bump |
| grounding | 判断材料 | grounding |
| オラクル | 事前に渡された指摘 | oracle |
| トリアージ | 仕分け | triage |

`オラクル` と `トリアージ` はカタカナだが、その分野の定訳とまでは言えない。カタカナであることは、そのまま残す理由にならない。

## 訳しすぎた語

定訳があるのに訳し直し、読み手が同じものだと気づけなくなった語である。

| 出がちな語 | 戻した語 |
| --- | --- |
| 札 | カード |
| 保管庫 | リポジトリ |
| 確定する | コミットする |
| 一時記憶 | キャッシュ |
| 利用事例 | ユースケース |
| 見出し札 | タブ |
| 定型文 | ボイラープレート |

平易な語を選ぶ規則だけを効かせると、この方向へ倒れる。訳しすぎも直訳と同じ失敗である。

## 一般の文書に馴染まない語

直訳ではないが、硬すぎて浮く語である。

| 出がちな語 | 直した語 |
| --- | --- |
| 瑣末 / 些末 | 些細 / 軽微 |
| 惹起する | 引き起こす |
| 企図する | 狙う |
| 峻別する | 区別する |

## 判断が割れる語

どちらでも通る語である。文書内で揃っていれば直さない。

| 語 | 対 | 備考 |
| --- | --- | --- |
| 既定 | デフォルト | どちらも定訳 |
| 差分 | diff | 文中は `差分`、コマンド名は `diff` |
| 記録 | ログ | 出力される実体を指すなら `ログ` |
| 作業 | タスク | 管理単位を指すなら `タスク` |
