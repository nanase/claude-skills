# label-apply — Issue / PR に分類ラベルを付ける

Issue / PR を出す直前に、その時点のラベル定義を読んで付けるラベルを判断し、付ける。固定の対応表は持たない（ラベルは時々で変わるため、ラベル定義を毎回読む）。

合うラベルが無ければ付けない。誤分類のコストは付け忘れより大きいので、迷ったら付けない。

## 手順

1. 付与の直前に `scripts/list-labels.sh` でラベル一覧（名前・説明・色）を取る
2. 各ラベルを「主題か」で判定し、当てはまるものだけ付ける
   - 説明文の範囲で判定
   - ラベル名は見出しにすぎない
   - 「触れている」でなく「主題である」かで見る
   - 説明文が限定する対象に触れていなければ、語感が近くても付けない
   - 迷ったら付けない
3. 判定したラベルを `scripts/apply-labels.sh issue|pr <番号> <ラベル名>...` で付与する
   - 付けるラベルが 0 件なら実行しない
   - 出力には既存のラベルも並ぶので、判定したラベルが含まれているかで確認する

## 出力

- 付けたラベル（無ければ「付けない」）
  - スクリプトの出力をそのまま貼らない。既存のラベルまで自分が付けたことになる
- 見送り理由があれば一言
  - Issue / PR 本文には書かない
